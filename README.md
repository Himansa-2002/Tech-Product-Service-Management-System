# TechSphere Lanka - Tech Product & Service Management System

## 📌 Overview

TechSphere Lanka is a comprehensive web-based platform designed to centralize technology-related services into a single ecosystem. The platform enables users to buy, sell, rent, insure, and manage technology products while also providing access to certified technician services.

The system was developed as an academic group project to address common challenges in Sri Lanka's technology service industry, including fragmented services, unreliable marketplaces, and limited access to premium technology equipment.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/TechSphere-Lanka.git
cd TechSphere-Lanka
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
MAILTRAP_TOKEN=your_mailtrap_token
```

---

## ▶️ Running the Application

### Start Backend Server

```bash
cd backend
npm run dev
```

### Start Frontend Server

```bash
cd frontend
npm run dev
```

Application will run on:

```bash
Frontend: http://localhost:5173
Backend: http://localhost:5000
```
